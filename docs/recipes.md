# 自然薯レシピの追加・更新

`content/recipes.json` がレシピの原本です。`recipes/` 以下のHTMLを直接編集しないでください。

## 追加する手順

1. 写真を `assets/images/` に置く。公開する写真は所有者が確認済みのものを使い、英数字とハイフンのファイル名にする。
2. `content/recipes.json` の `recipes` 配列に既存の1件をコピーして追加する。`slug` は重複しない英小文字・数字・ハイフン。公開後はURLを維持するため変更しない。
3. `title`、`category`（`jinenjo` または `mukago`）、`categoryLabel`、説明、写真・実寸、`yieldLabel`、材料のペア、手順の見出しと本文、コツ、更新日を入力する。未確認の人数・所要時間・栄養値は補わない。
4. `node --test tests/recipes.test.mjs` を実行する。
5. `node scripts/build-recipes.mjs` を実行し、一覧・詳細・関連レシピ・サイトマップを更新する。`node scripts/build-recipes.mjs --check` で生成物の一致を確認できる。
6. スマートフォン・PCで確認し、データ・写真・生成されたHTML・サイトマップをまとめてGitHubに保存する。

GitHub Actionsの公開処理でも同じ検証・生成を実行するため、レシピを増やしても一覧やサイトマップを手で書き換える必要はありません。テンプレートは `scripts/build-recipes.mjs`、見た目は `assets/css/recipes.css`、検索・絞り込みは `assets/js/recipes.js` です。外部ライブラリとデータベースは不要です。

## 料理の内容

- とろろごはん・むかごご飯は、ユーザー承認のもと基本レシピとして整理。調理方法を確認した資料は各詳細ページの参考リンクに記録。
- アンチョビガーリックは2026-11-26提供の材料・手順を使用。ゆで湯の塩は1%、ゆで時間は約5分。
- 梅しそあえは提供された材料を使用し、食材は自然薯と確認済み。作り方はユーザー承認の基本手順。

- バターしょうゆ焼きは2026-11-26提供の料理写真・材料・5つの手順を使用。山芋の表記を自然薯に統一し、分量・2cm角の切り方・火を止めてからしょうゆと青のりを絡める順序を維持。

ヘッダーとフッターは自然薯紹介ページから共通部分を読み取って生成します。ナビゲーションを変更したときは再生成してください。
